A06 GameBoost — PWA web instalable

Esta carpeta contiene una aplicación web progresiva (PWA). No es un APK Android.
Para instalarla como aplicación en la pantalla de inicio, primero debe publicarse en un sitio HTTPS compatible (por ejemplo, GitHub Pages).

Pasos generales:
1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En el repositorio, entra a Settings > Pages.
3. Activa la publicación desde la rama principal y la carpeta raíz.
4. Abre la URL HTTPS que GitHub Pages proporcione usando Chrome en tu Samsung.
5. En Chrome, abre el menú ⋮ y elige "Instalar aplicación" o "Añadir a pantalla de inicio" (el texto varía según la versión).

La app no solicita permisos, no controla los ajustes del teléfono y no mide FPS ni temperatura de CPU/GPU. Sus opciones son recomendaciones y controles de interfaz.
